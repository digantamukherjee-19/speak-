# Text-to-Speech App

A simple Python application that converts written text into speech. The user enters text, and the application reads it aloud.

## Features

- Converts text into speech
- Allows the user to enter custom text
- Speaks the entered text aloud
- Simple and easy to use

## Technologies Used

- Python

## How to Run

1. Make sure Python is installed on your computer.
2. Clone or download this repository.
3. Open the project folder.
